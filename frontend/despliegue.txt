Instrucciones de Despliegue Local

Requisito previo:
Instalar pnpm globalmente si aun no esta instalado:
   npm install -g pnpm

1. Verificar que Node.js este instalado:
   & 'C:\Program Files\nodejs\node.exe' -v

2. Abrir una nueva terminal de PowerShell y ubicarse en el frontend:
    cd C:\Users\jesia\OneDrive\Desktop\appINV\frontend

3. Instalar dependencias:
   pnpm install

4. Opcional pero recomendado: crear un archivo `.env.local` para definir la
   URL base del backend:
   NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000

5. Si vas a cargar capillas desde el mapa de la Iglesia, define tambien el
   endpoint real y, si aplica, el token que descubras en la pestaña Network:
   MEETINGHOUSE_API_URL=https://maps.churchofjesuschrist.org/api/maps-proxy/v2/locations/clusters
   MEETINGHOUSE_API_TOKEN=ncqmw6

6. Verificar que el backend este levantado en:
   http://127.0.0.1:8000

7. Levantar el frontend en desarrollo:
   pnpm dev

8. Abrir la aplicacion en el navegador:
   http://localhost:3000

Produccion local:

1. Generar el build:
   pnpm build

2. Iniciar el servidor de Next.js:
   pnpm start

3. Exponer el puerto 3000 detras de un proxy reverso si se publica hacia
   internet. Next.js recomienda usar `next start` detras de nginx o un
   proxy equivalente para self-hosting.

Importante:
El frontend toma la URL base del backend desde
`NEXT_PUBLIC_API_BASE_URL`. Si no defines esa variable, usa por defecto:
`http://127.0.0.1:8000`

La carga de capillas usa `MEETINGHOUSE_API_URL`. Si no la defines, el
frontend usa por defecto el endpoint de clusters descubierto desde el sitio.
Si el token cambia o deja de responder, actualiza `MEETINGHOUSE_API_TOKEN`.
